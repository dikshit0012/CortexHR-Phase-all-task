# Model Card: <model name and version>

> Every number must come from a command you ran or a file in this repository. Write "not verified" instead of guessing.

1. **Model name / version** - artifact name, version string, trained-at date, library versions.
2. **Overview** - what it does, why it exists, intended users.
3. **Intended use** - appropriate, human-reviewed uses.
4. **Out-of-scope use** - what it must not be used for (automatic hiring, firing, pay, promotion decisions).
5. **Dataset** - name, source, size, features, target, synthetic vs real, missing values, preprocessing, limitations.
6. **Model and methodology** - algorithm, features, training, validation, baselines, configuration.
7. **Evaluation** - only the metrics that apply, with the command that produced them.
8. **Fairness evaluation** - groups, metrics, results, sample-size limits, mitigation, what was NOT tested.
9. **Limitations**
10. **Ethical considerations** - harms, privacy, discrimination risk, human oversight.
11. **Deployment information** - endpoint, artifact, dependencies, how it loads, what was actually tested.
12. **Monitoring** - drift, performance, fairness, alerting, and their limits.
13. **Release recommendation** - RELEASE / RELEASE WITH WARNINGS / INTERNAL DEMONSTRATION ONLY / NOT READY FOR RELEASE, with reasons.
